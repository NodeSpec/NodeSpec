# Security Policy

## Reporting a vulnerability

Email **contact@nodespec.io** with the subject line `SECURITY`. Include
reproduction steps and the deployment shape (community container / hosted).
You will get an acknowledgment within 72 hours.

Please do not open public issues for suspected vulnerabilities until a fix
has shipped.

## Scope

This repository covers the community edition: the self-host container
(frontend, gateway, edge functions, MCP server) and its deployment tooling
under `deploy/selfhost/`. The hosted service at nodespec.io has its own
surface and is monitored separately — reports about it are welcome at the
same address.
